# About

## Add-on Structure
SurfacePsycho is only made of : 

- An asset library of **GeometryNodes modifiers** and some shapes presets
- A CAD file importer and exporter
- Some buttons for efficiency (`N panel > Item > SurfacePsycho`)

## Project Structure
Repositories :

 * [Bezier-Quest](https://github.com/RomainGuimbal/Bezier-quest) : Where all the nodes, icons and tests are made
 * [Here](https://github.com/RomainGuimbal/SurfacePsycho) : The add-on, his library and code
 * [SurfacePsycho Sample Files](https://github.com/RomainGuimbal/SurfacePsycho-Sample-Files) : User files library

Feed and discussion :

 * [Discord](https://discord.gg/zUmFejwV8G) : To discuss, connect, help and get helped
 * [blenderartists.org](https://blenderartists.org/t/surfacepsycho-addon-project/1487629) : News and feedback

## Get involved
Helping directly on the core development is extremely appreciated but can get advanced very fast. However you can also use SurfacePsycho primitives and operations to make your own tools and share them with everyone. There is a lot of areas where all the component are there but the end-user tool haven't be made by lack of time.
