`MODIFIER` `TOOL`

SP surfaces are dependent to a specific index order to work, so this tool reorders it in case you have a grid with incorrect vertices index.

<img src="https://github.com/RomainGuimbal/SurfacePsycho/assets/39882829/26ba68e1-6bf4-42af-ad91-10819f8763ce" height="300">

### Use cases
Apply it once after : 
* Separating two grids from the same mesh objects
* Making a grid from a subdivided quad or any manually made grid

As a consequence this simplifies greatly the workflow, especially if you want to convert your mesh models to SurfacePsycho
