NURBS to Bezier splits a multi-span NURBS patch into multiple single span (Bezier) patches. It's a compound type operation. Therefore it can only work if added to a [compound object](https://github.com/RomainGuimbal/SurfacePsycho/wiki/2.-SP-Objects). To use it you need to choose a NURBS object as an operation target. In order to get individual Bezier patches, use [explode compound](https://github.com/RomainGuimbal/SurfacePsycho/wiki/Explode-Compound) on the compound object.
