# SP - Switch Curve Direction
Flips the indexing of curves. Can be either used as a modifier or a destructive tool

## Usage example
You have two wires you want to connect like this :
![alt text](<../../Images/switch curve direction 2.jpg>)

Unfortunately one wire is reversed, so it makes it anoying to select the right segments on the surfaces' ``SP - Blend surface`` modifier (one should be decremented, the other incremented).
![alt text](<../../Images/switch curve direction 1.jpg>)

Using `SP - Switch Curve Direction` fixes the issue
