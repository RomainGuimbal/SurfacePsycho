`MODIFIER` [`MESHING`](https://github.com/RomainGuimbal/SurfacePsycho/wiki/3.-Modifers-and-Tools#meshing-modifiers)

Takes instances of individual shapes control geometries as input. Each instance must have a type assigned with [Set Patch Instance Type](https://github.com/RomainGuimbal/SurfacePsycho/wiki/Set-Patch-Instance-Type-[Node-Group]) node group.
