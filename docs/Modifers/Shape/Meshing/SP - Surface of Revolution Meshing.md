# SP   Surface of Revolution Meshing

`MODIFIER` `MESHING`

To mesh surfaces of revolution. It takes as input a first edge which defines the axis of symmetry and a second mesh island which is the control geometry of the segment to revolve. Revolution less than 360° are done through trimming (in accordance to the STEP norm). A modifier have been added to make the operation easier : [`SP - Adjust Revolution Sweep Angle`](../../Trim/SP%20-%20Adjust%20Revolution%20Sweep%20Angle.md)
