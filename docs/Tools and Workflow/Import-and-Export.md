# Import
.STEP/.IGES Importer is in progress. Expect variable quality.

# Export
### .STEP .IGES
SurfacePsycho exports its geometric entities as **.STEP** or **.IGES** files 
> Note : All the other native exporters are supported but will be convert your model to polygons, STEP data will be lost

### Quick export
Button in `N panel > Item > SurfacePsycho > Quick export`

#### File location :
* Same folder as your blend file
* If the blend file never been saved : Temporary File Path (Set in user preferences)
