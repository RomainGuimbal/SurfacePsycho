# Edit Trim Contour
Trim contours in SurfacePsycho are defined with the [wire system](https://github.com/RomainGuimbal/SurfacePsycho/wiki/Editing-Wires). The wires are projected over the X-Y plane of the object. The X axis represents the U axis and Y the V axis.
