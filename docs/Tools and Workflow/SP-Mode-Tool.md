From the left tool bar in `Object mode` and `Edit mode`, you can activate the `SP Mode Tool`

The enabled, it gives you several overlays and shortcuts to speedup your workflow :

## Overlays
### Segment Selection
- In Object mode, segments are highlighted at cursor hover. Selected one by pressing `Ctrl`+`Left Click`. Select more by using `Ctrl`+`Shift`+`Left Click`.
- In Edit mode, vertices tagged as Endpoints are shown with a black square.

## Keymap
A specific [keymap](https://github.com/RomainGuimbal/SurfacePsycho/wiki/6.-Keymap) is toggled by the tool. It tries to minimize overlaps with Blender default keys you usually need for surface editing.
