## Install 
1. In ``Edit > Preferences > Get Extentions`` Search for "Surface Psycho", click Install.

2. In `Edit > Preferences > Add-ons > SurfacePsycho` click `Add assets path`

[More details on installation and setup here](./10_Install%20and%20Setup.md)

## Start designing

1. Add a SurfacePsycho object : ``Shift``+``A`` > `Surface`, or ``Shift``+``A`` > `Curve` and select one in the bottom section. [Understand what SP objects are here](./Workflow/SP%20Objects.md)

2. ``Tab`` to get in edit mode. SP objects are simply mesh objects with specific attributes. You can edit it like any mesh [More details here](./Workflow/Destructive%20editing.md)

3. Add modifiers for non-destructive editing. If you have setup the library correctly, SP modifiers should appear in the modifier list under ``SurfacePsycho`` sub-menu. [More details here](./Workflow/Modifers.md)

## Export your design
Export selected SurfacePsycho objects as STEP files with `N panel > SurfacePsycho > Quick export` (saved in current .blend folder). [More details here](./Workflow/Import%20and%20Export.md)
